# Legal Notice and Privacy Policy 2.2.6.10

This release supports both webtrees 2.2 and webtrees 2.3. The module no longer depends on the concrete Core `PrivacyPolicy` implementation and keeps its privacy-policy page, footer, and analytics handling module-owned.

The Google Charts privacy-service option and notice are now shown only for webtrees versions that still use Google Charts. The option remains available on webtrees 2.2 and is hidden on webtrees 2.3.

Administrators can select the applicable legal jurisdictions independently of the physical server location. Privacy-notice integrations also accept scalar values from older or simpler provider modules while retaining the documented list format.

The registration section describes the current Core acceptable-use notice according to `SHOW_REGISTER_CAUTION`. It does not claim that webtrees stores a versioned acceptance record; that functionality remains a Core topic tracked in [webtrees#5399](https://github.com/fisharebest/webtrees/issues/5399).
